# MUI Base Components

**These already exist. Do not rebuild them.**

This section is here for two reasons.

### 1. To see what you already have

Step 2 of planning asks you to split components into **reuse** and **build new**.
Everything here belongs to reuse. There is no reason to build your own table, button, or text field.

Need something that is not here? Check the [MUI component list](https://mui.com/material-ui/all-components/) first.
Build it yourself only when it is missing there too.

### 2. To see your own tokens applied

The official docs show MUI's default theme. This section shows **your project theme**.

Change the colors and fonts in `src/styles/theme.js` and these screens change with them.
After swapping tokens in step 3, **check here**. Is the button too heavy? Does the table read well? Is the type the right size?

---

**Do not edit the files in this section.** To change how something looks, change `theme.js`.
That is what working with a design system means.
